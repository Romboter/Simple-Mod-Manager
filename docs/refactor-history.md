## Batch Process

Batches were done via `isolation: "worktree"` sub-agents, each restricted to its own target file plus new files, forbidden from touching `Core.cs`/`Startup.cs`/`MainWindow.xaml`/each other's files/`CLAUDE.md`. Commits were cherry-picked one at a time into `refactor/mainwindow-feature-services` with a full rebuild + method-count verification after each — see `docs/worktree-incidents.md` for isolation failures encountered along the way and how they were fixed. The final solo reviews (Compatibility follow-up, CloudAuth, GameLaunch, ModUsage, Core) were done directly in-session rather than via worktree sub-agents.
